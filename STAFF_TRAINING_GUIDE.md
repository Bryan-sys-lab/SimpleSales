# Duka POS - Staff Quick Reference

## Getting Started

### First Time Setup (Owner Only)
1. Open app and create owner account
2. Set your 4-digit PIN (remember this!)
3. Add products to inventory
4. Add staff members (Settings > Staff)
5. Create first backup immediately (Settings > Backup)

### Daily Login (All Staff)
1. Open app
2. Select your name from dropdown
3. Enter your 4-digit PIN
4. Tap products to start selling

---

## Selling

### Cash Sale
1. Tap products to add to cart
2. Adjust quantity with +/- buttons
3. Tap **CASH** button
4. Sale is recorded automatically

### M-Pesa Sale (If Enabled)
1. Add products to cart
2. Tap **M-PESA** button
3. Enter customer phone number (07XXXXXXXX)
4. Customer receives STK push on phone
5. Customer enters M-Pesa PIN
6. Wait for confirmation (usually 10-30 seconds)

### Cart Management
- Tap product again to add more
- Use +/- to adjust quantities
- Tap trash icon to remove item
- Total updates automatically

---

## Inventory

### Add Product
1. Go to **Inventory** tab
2. Tap **+** button
3. Fill in:
   - Name
   - Category (optional)
   - Cost Price (what you paid)
   - Sell Price (what customer pays)
   - Stock quantity
   - Reorder level (when to restock)
4. Tap **Save**

### Edit Product
1. Tap product in inventory list
2. Update any field
3. Tap **Save**

### Adjust Stock
1. Tap product in inventory
2. Tap **Adjust Stock**
3. Enter new quantity OR +/- amount
4. Add reason (optional)
5. Tap **Save**

---

## Reports

### View Sales
1. Go to **Reports** tab
2. Select date range
3. See total sales, profit, items sold

### Filter Reports
- By date: Today, This Week, This Month
- By staff: Select staff name
- By payment: Cash or M-Pesa

---

## Settings (Owner Only)

### Add Staff Member
1. Go to **Settings** tab
2. Tap **Add Staff**
3. Enter name and 4-digit PIN
4. Tap **Save**

### Reset Staff PIN
1. Go to Settings
2. Tap **Reset PIN** next to staff name
3. Enter new 4-digit PIN

### Enable M-Pesa
1. Go to Settings
2. Turn on **M-Pesa** toggle
3. Enter:
   - Your email (for backend account)
   - Password (min 6 characters)
   - PayHero Channel ID
4. Tap **Connect**
5. Wait for setup to complete

### Sync Products (M-Pesa Required)
1. Go to Settings
2. Tap **Sync Now**
3. Products uploaded to backend
4. Now available for M-Pesa sales

### Backup Data
1. Go to Settings
2. Tap **Export Inventory**
3. Choose location to save .xlsx file
4. **IMPORTANT:** Copy to safe location:
   - Google Drive
   - Email to yourself
   - USB drive
   - Another phone

### Restore Backup
1. Reinstall app (if needed)
2. Go to Settings
3. Tap **Import Inventory**
4. Select .xlsx backup file
5. Confirm restore

## Common Problems

### "Wrong PIN"
- Check you selected correct username
- Try again (you have 5 attempts)
- Ask owner to reset your PIN

### "Too many wrong PINs"
- Wait 30 seconds
- Try again
- Or ask owner to reset PIN

### "Not enough stock"
- Check inventory for actual stock
- Adjust stock if missing items
- Cannot sell more than available

### "Payment failed" (M-Pesa)
- Customer may have cancelled
- Insufficient funds in customer account
- Wrong phone number entered
- Use cash instead

### "No internet" (M-Pesa only)
- M-Pesa requires internet
- Use cash sale instead
- Check WiFi or mobile data

### App frozen or crashed
1. Close app completely
2. Reopen app
3. Check last sale recorded
4. If problem continues, contact support

### Lost phone / App deleted
1. Install app on new phone
2. Import backup file from safe location
3. All data restored
4. **Without backup, data is lost forever**

## Security

**PIN Security:**
- Never share your PIN
- Change PIN if you think someone knows it
- Owner can reset any staff PIN

**App Security:**
- App auto-locks after 4 minutes idle
- Sign out manually if leaving till unattended
- Lock phone when not in use

**Data Security:**
- Backups contain all business data
- Keep backup files private
- Don't send backups via public channels
