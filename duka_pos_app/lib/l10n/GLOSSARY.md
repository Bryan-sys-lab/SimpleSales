# SimpleSales translation glossary

These are product terms, not literal words to translate differently on each
screen. Keep them consistent in Swahili copy and receipts.

| English | Swahili | Usage |
| --- | --- | --- |
| shop | duka | A business location/tenant |
| sale | mauzo | A completed transaction |
| sell | uza | The till action |
| stock | bidhaa / stoo | Use *bidhaa* for products and *stoo* for stock control |
| owner | mmiliki | Shop owner role |
| manager | msimamizi | Manager role |
| cashier | muuza bidhaa | Till operator role |
| credit | mkopo | Customer credit, not a bank loan |
| customer | mteja | Customer record |
| receipt | risiti | Printed or PDF receipt |
| report | ripoti | Business report |
| analytics | uchambuzi | Charts and business analysis |
| sync | sawazisha | Device/cloud synchronization |
| offline | bila intaneti | The app still works without a network |
| big cup | kikombe kikubwa | Tank serving name; never “shot” |
| small cup | kikombe kidogo | Tank serving name; never “shot” |

Untranslated feature messages deliberately fall back to English while a
translation is being completed. The ARB validator checks that this fallback
cannot break placeholders or introduce an invalid key.
